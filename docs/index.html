Regulatory Authority Graph

Combined authority web for the requirements catalog — every standard, every parent it inherits authority from, every lateral reference.

Read bottom-up: each arrow points from a standard to its authority parent. Solid arrows are authority edges; dotted arrows are lateral references. Click any node to open that standard’s canonical source. Hover for the full title and local PDF path.
