# Registries

Structured captures of government registries used as reference data for requirements and compliance.

## Organization

```
registries/
└── nara-cui/          # NARA CUI Registry (categories, markings, handling)
```

## Schema

Registry files conform to their respective schemas in `schemas/`.

| Registry | Schema |
|----------|--------|
| NARA CUI | `schemas/cui-registry.schema.json` |

## Citation Format

All registry captures use MLA citation format including date accessed, since registry content may change over time.
